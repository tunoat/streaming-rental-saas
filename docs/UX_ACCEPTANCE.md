# Thai admin UX

Super Admin sees ร้านค้า and ผู้ดูแลระบบ. Owners see ภาพรวม, ออเดอร์, ลูกค้า, บัญชีสตรีมมิง, การเงิน and ตั้งค่า. Staff see the operational subset. The overview checks inventory, profiles, customers and rentals from API responses. Job internals appear under รายละเอียดขั้นสูง. Current user/store preference persistence, mobile coverage across all roles and comprehensive review screens remain pending.

Selected statuses: รอจัดสรร (PAID_WAITING), กำลังส่งมอบ (DELIVERING), กำลังใช้งาน (ACTIVE), รอยืนยันถอนสิทธิ์ (REVOCATION_PENDING). See TEST_REPORT for browser evidence.
